# 本地使用与隐私

第一次制卡的详细步骤和可复制指令见[首次建卡指南](../skills/manage-asset-atlas/references/first-card.md)。

## 保存和查看

选择一个固定的私人资产库目录，以后登记其他项目继续复用。首次制卡只修改这个资产库，不修改被登记项目；常规维护中的项目反向登记由另一次明确请求决定。

| 场景 | 使用方式 |
|---|---|
| 第一次查看 | 构建通过后，由助手打开 `asset-atlas.html#新卡编号`；无法自动打开时提供文件路径 |
| 下次再看 | 双击固定位置的 `asset-atlas.html`，也可为它建立桌面快捷入口 |
| 内容更新后 | 在同一资产库重新构建，刷新页面；快捷入口仍指向同一个文件 |
| 离线查看 | 页面、卡片、头像和图表运行时都已内嵌，无需保持终端或本地服务运行 |
| 卡片密码保护 | 运行 `npm run serve:private`，在详情中加锁；需要保持 Node 服务运行 |

## 读取范围和网络

首次制卡默认只读取当前项目的 README、依赖配置和必要目录信息，不读取 `.env`、密钥、日志或业务数据，也不运行被登记项目。卡片只写已确认的用途、位置和启动方式；没有运行验证的信息标记未核验。

Asset Atlas 页面没有上传卡片的接口，不主动向其他服务发送卡片资料；外部网址或应用入口在点击后才打开。Node 私密模式会向你运行的同源服务请求数据、提交解锁密码和保存加锁选择。初次克隆仓库、安装依赖需要联网。

**本地编程助手不一定使用本地模型。** 如果助手连接云模型，读取到的项目文字可能发送给模型服务，按你所用助手和模型的设置处理。本项目的本地存储方式不代表“所有资料绝不离开电脑”。

安装 skill 使用的 Skills CLI 是独立工具，其官方说明包含匿名安装统计和关闭方式：设置环境变量 `DISABLE_TELEMETRY=1`。这与 Asset Atlas 页面本身的行为不同，详见 [Skills CLI 文档](https://skills.sh/docs/cli#telemetry)。

## 分享前检查内容

**默认静态构建的 `asset-atlas.html` 和 `dist/index.html` 包含整个资产库的资料，包括所有卡片的原始 Markdown。** `#T-编号` 只是定位到一张卡，筛选、折叠或隐藏内容不会从文件中删除其他资料。请把它当作私人资料文件保管；发送文件或部署到公开网站，会一并分享其中的全部内容。

首次制卡流程不提交、推送或部署，仓库中的卡片源文件也不要误推到公开仓库。记录凭证时只写存放位置，不写密码、Token 或 Cookie。

需要跨设备查看时，可采用[私有仓库 + Vercel 登录保护](usage.md#部署到-vercel)：先用虚构示例部署，启用 Vercel Authentication / All Deployments 并验证未登录访问被拦截，再上传自己的卡片。Hobby 免费套餐可用；源码仓库设为 Private 不会自动保护网站。私有部署仍会把资料上传到 Git 托管服务和 Vercel，不能视为只保存在本机。

分享单张卡片的改进方向是：另生成只含选中卡片的副本，默认保留名称、用途、头像和确认可公开的网址，去掉私人路径、主机、内部链接等信息，让用户预览后再导出。**这个独立分享导出尚未实现。** 当前的 Markdown 下载保留原卡内容，不能当作脱敏后的分享文件；要分享截图，也请先检查画面里的资料。

## 密码保护的范围

[`npm run serve:private`](usage.md#卡片密码保护-node-模式) 使用独立页面外壳和后端数据接口。加锁后，未解锁的访问者只能取得封面信息（编号、名称、头像、分类、状态、核验日期），无法从该接口取得完整摘要、字段、链接、Markdown 或图表。毛玻璃只是视觉提示，不承担保护详情的职责；名称和头像仍属于可获取的封面信息。

一把密码可以查看所有私密卡片，也可以修改加锁选择。默认没有整站登录门槛，未加锁卡片始终可见；部署前在本机选好需要保护的卡片，并将 `locks.json` 一起保留。丢失该文件会丢失加锁选择。

Markdown 源文件、`.asset-atlas/data.json` 和密码文件仍是本机明文，已下载的副本也不会被收回。不要公开这些文件或整个项目目录；只通过内置 Node 服务提供网页。静态构建、旧的离线 HTML 和 Vercel `dist/` 不读取加锁选择，不能用它们替代私密服务。
