# 制作我的第一张卡

在想整理的项目里打开能读写本地文件、执行命令的编程助手。需要 Git 和 Node.js 22 或更新版本，无需部署网站。

已安装 `manage-asset-atlas` 时，可以直接让助手“使用 manage-asset-atlas，把当前项目制作成第一张资产卡并打开本地预览”，并告诉它资产库目录。安装本身不会扫描项目或生成卡片。

执行此流程的助手：优先复用用户指定或项目明确登记的现有资产库；有多个候选时让用户选定，没有找到时先让用户选一个固定目录，不默认在当前项目或 skill 安装目录建库。只有用户明确要求新建资产库并指定新目录时才克隆仓库。下面的完整指令包含这项新建授权；其中示例路径不是未指定目录时的默认值。

## 完整可复制指令

不安装 skill 也可以复制整段指令。先将 `~/my-asset-atlas` 换成自己选定的固定目录；已有资产库则填写它的路径，之后整理其他项目继续复用。

```text
请把当前项目制作成一张 Asset Atlas 资产卡，并打开本地预览。
我的私人资产库目录是 ~/my-asset-atlas；如果该目录不存在，请在那里新建资产库。

1. 确认当前项目目录并检查已有改动。只读取项目 README、依赖配置、
   必要目录信息；不读取 .env、密钥、日志或业务数据，不运行被登记项目。
2. 如果资产库目录不存在，从 https://github.com/xPeiPeix/asset-atlas
   克隆到该目录；如果已存在，先确认是可用的资产库，不覆盖已有文件。
   已有目录不是资产库时停止写入，让我另选目录。
   这是我的私人本地副本，允许记录我的真实项目，不用于公开演示；
   上游仓库的演示卡片继续保留虚构资料，不把真实资料写回上游。
3. 阅读资产库中的 AGENTS.md、README 和 skills/manage-asset-atlas/SKILL.md。
   按名称、目录、仓库和入口查重；已有同一项目卡片则更新原卡，保留编号。
   确认是新资产后，在 tools/ 和 archive/ 中查找最大编号并加一，
   T-000 保留给资产地图自身，不补空号、不复用已归档编号。
   按模板记录名称、用途、分类、位置和已知启动方式；
   未实际验证的运行状态标记为未核验，不猜测网址、部署或备份信息。
4. 创建或更新 Markdown 卡片，保留 README 的简洁介绍。新卡根据用途制作专属头像：
   有 ImageGen 可生图；没有时直接编写 SVG 或 Canvas 绘图代码，
   按 skill 中的 references/code-avatars.md 转为 256×256、带透明背景、
   不超过 32 KiB 的 WebP，保存为 assets/avatars/新卡编号.webp 并引用。
   已有卡片的头像保留；只想快速预览或暂时无法导出时，说明情况后
   复用一枚示例头像，复制为与新卡编号一致的文件，不要求另接生图服务。
   保留原有示例、其他卡片和已有改动。简单项目不必为了展示补流程图。
5. 只修改资产库，本次不修改当前项目，包括它的 AGENTS.md。
   在资产库中按需运行 npm ci，然后运行 npm run check。
   检查失败时说明原因，不把生成页面成功说成被登记项目运行正常。
6. 检查通过后，用本机浏览器打开生成的 asset-atlas.html，并带上实际卡片
   编号的片段（如 #T-007），直接进入详情。
   告诉我卡片文件和页面的完整路径；不能自动打开时给出手动打开方式。

只在本地完成，不连接远端主机，不提交、不推送、不部署。
```

成功后会得到一张 Markdown 卡片和可直接打开的地图：列表里有项目名称和头像，详情里有用途及已知使用信息。没有 ImageGen 也可用[原生代码绘图](code-avatars.md)制作专属头像；现成头像仍可用于快速预览。

## 以后如何查看

双击固定资产库中的 `asset-atlas.html` 即可查看，也可为它建立桌面快捷入口。更新卡片后在同一个资产库重新构建，再刷新页面；无需保持终端或本地服务运行。自动打开浏览器取决于助手权限，不能自动打开时仍可手动打开生成文件。

## 资料与分享

- 克隆仓库和安装依赖需要联网。资产卡保存在本机，但本地编程助手可能使用云模型，读到的项目文字可能发送给模型服务；按所用助手和模型的设置处理，不承诺所有数据都不离开电脑。
- 卡片只记录必要信息；凭证仅记录存放位置或管理方式，不记录密码、Token、Cookie、私钥或连接串的值。
- 生成的 HTML 包含整个资产库的卡片和原始 Markdown。`#T-编号` 只定位一张卡，筛选、折叠或隐藏内容不会从文件中删除其他资料。发送 HTML、公开部署或把卡片源文件推到公开仓库都会公开相应资料。
- 当前没有单张卡片的脱敏分享导出。Markdown 下载保留原卡内容；分享文件或截图前，先检查实际包含的资料。
